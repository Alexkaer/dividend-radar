# 息壤 · Dividend Radar

赛博朋克 A 股红利看板：沪深北全市场滚动现金股息率严格大于 5.0%，且总市值严格大于 500 亿元。支持搜索、市场筛选、排序、本地自选、CSV 导出及逐笔分红明细。

## 数据口径

来源：东方财富公开行情及分红送配接口。过去 365 天内已除息且标记为「实施分配」的税前每股派息之和，除以最新价。未到除息日的方案不纳入。未对窗口内送转、拆并股、配股调整，特殊股本变动公司需另行核验；一次性特别分红可能推高数值。该指标不是供应商标准 TTM 股息率，也不是预期收益。

页面展示行情源时间与抓取时间。覆盖数含源站返回的全部 A 股记录；无有效价格或无派息记录的股票不进入结果。未排除 ST，不覆盖港美股、基金和 B 股。

## 更新和部署

页面打开自动刷新，按钮可手动刷新；已取消每日定时任务。GitHub Actions 仅用于代码部署和显式手动维护备用快照。全量抓取和覆盖检查通过后原子替换快照；失败保留旧文件，部署旧快照后将任务标记失败。页面对超过 36 小时的快照或行情明确提示。

静态页面部署到 GitHub Pages，无 API 密钥。公开接口可能限流或变化，可在 Actions 日志查看失败原因。

本地更新：`python scripts/update_data.py`；预览：`python -m http.server 8000`。

## 国资标注

以东方财富公司资料中的企业性质、实控人字段分类为央企、中央金融国企、地方国企。其他公司查询最新前十大股东，对中央汇金、中国证券金融及明确国资机构作国资参股标注，并展示股东、比例和报告期。国资参股不等同国资控股，包含被动财务投资；未穷尽穿透持股关系，未识别不代表无国资。资料随页面刷新更新，失败时保留原核验日期。

## BOLL 与趋势

刷新时为全部入选股票读取320根前复权日K，截断至行情快照日期；按ISO自然周取最后一个交易日收盘聚合周线，本周未完成时明确标识。BOLL(20,2)使用20期均值和总体标准差；%B≥0.8为日上/周上，≤0.2为日下/周下，其余为日中/周中；超出上下轨另行注明。趋势为BOLL中轨较上期变化超过+0.1%向上、低于-0.1%向下，其余走平，日周分别展示。需要至少21根有效K线；不足、停牌导致日期落后或取数失败均标明，不伪造信号。CSV包含位置、日周趋势和计算日期。

验证：`python scripts/test_technicals.py`。

## 行业与公司财报分析

来源东方财富利润表、现金流量表，按抓取日已披露公告筛选，无未来报告。行业基于全A股同分类、同一报告期样本，至少3家、披露覆盖不低于上期70%；最新季度不足则回退上一期并明确标记。展示营收增速中位数、盈利样本归母增速中位数、盈利占比和样本数量；低基数影响不能完全排除。

公司展示最新累计营收、归母净利润、扣非利润、经营现金流与同比；亏损、扭亏优先识别，任一主要增速≤−10%标承压，营收≥5%、归母≥10%、扣非≥0%且非已知扣非亏损基数标向好，其余可比盈利标平稳。现金流/归母利润仅用于非金融企业的辅助提示，不代表严谨的现金分红覆盖倍数。银行保险等不采用该比率评价。行业规则及局限在详情可展开查看。分析为规则生成，不能替代财报审计、公告阅读或投资判断。

验证：`python scripts/test_fundamentals.py`。

## 图片分享

代码推送部署程序及备用快照；显式手动运行可维护备用快照，浏览器刷新不需要GitHub令牌。

股票名称旁及详情内的分享按钮，在浏览器本地用Canvas生成1080×1660高清PNG，含股息率、国资、BOLL、日周趋势、业绩摘要及数据日期。顶部「分享看板」导出当前筛选全部行，空结果时禁用。可预览、下载PNG，支持文件分享的手机提供系统分享入口，用户自行选择目标。无服务端截图和第三方图片生成接口。图片不含自选账户信息；来源与规则提示直接标注在图片中。

## 大盘概览

工作台入口 `market.html`，包含上证、深证、创业板、科创50、沪深300、北证50、上证50、中证500。广度按全A股估值行情有效价格与涨跌幅统计，平盘包括源站停牌记录。涨跌停是东方财富股池收录数，不是跨交易所、跨ST口径统一的涨跌停全量数。

量能为沪深主指数成交额合计，最近10个交易日；不含北交所，不叠加成分指数。展示日环比和最近5日成交额相对之前5日的变化。行业榜从东财全部行业板块（可能有层级重叠）分别按当日、最近5交易日涨幅选前15，用2根、6根日K逐条核对；默认当日，可切换近5日，不混入概念板块。

情绪分=60%上涨占比+25%涨停池占比+15%指数强弱分；指数分=clamp(0.5+沪深平均涨幅/6,0,1)。阈值≥75活跃、≥55偏强、≥45分歧、≥25偏弱、其余低迷。数据不足时不打分。属于当日规则描述，不预测未来。

显式手动维护任务分别刷新红利与大盘JSON，单项失败保留原快照并将任务标红；禁止混用不同交易日生成一个大盘快照。首次更新后可用 `python scripts/update_market.py` 独立刷新，测试 `python scripts/test_market.py`。

## 访问时更新与手动刷新

`live-data.js` 在浏览器通过公开JSONP接口获取全A股行情、分红、企业性质、财报、K线和行业榜。打开页面先展示本地缓存或随站点发布的备用快照，随后自动取新数据；按钮触发重新取数，刷新过程中防止重复提交。完成后仅缓存到访问者浏览器，无需GitHub令牌，不在网页中暴露任何私有凭据。行业与财报样本较多，首次刷新可能需要数十秒。

GitHub Actions不再设置schedule。手动工作流仅作维护备用JSON，不承担访客刷新。数据源失败明确提示，保留上次快照及原日期；部分财报资料失败时保留原核验时间。盘中行情会变化，分项请求时间略有差异；盘中累计成交额不可与完整交易日直接比较。

## 硬件AI科技观察池

`hardware.html` 提供独立产业链观察页，初始28只A股代表性公司，分算力芯片、服务器、光通信、PCB与材料、液冷与散热、电源、存储与接口、连接与终端八类。分类用于主题观察，不是官方指数、非全量AI公司，不代表AI收入占比。主营依据来自东方财富公司资料，可在详情查看源链接。

展示最新价、涨跌幅、成交额、市值、PE TTM、换手率、逐股行情时间；分类涨跌幅是有效成员等权平均，不替代行业指数。访问自动刷新和手动刷新使用现有公开数据源，不接入妙想，不设置定时任务。支持方向/名称/代码/主营筛选、涨跌幅/成交额/市值排序和CSV。

自定义添加先查询验证行情，代码去重，仅保存在当前浏览器；可移除自己添加的股票，不修改东方财富自选账户。`data/hardware-universe.json`为预置观察池，`data/hardware.json`仅为加载失败时的备用快照，维护命令 `python scripts/update_hardware.py`。

默认展示每方向预置观察池按最新总市值排序的前2只「规模龙头」，可切换全部观察标的；这是池内规模排序，不是全市场份额认证。方向卡及下拉选项均可筛选列表。

龙头取上市以来前复权日K最高价；返回条数与源站dktotal、末日匹配时标历史高点，否则标区间高点。覆盖日期、条数、高点日期和回撤公式可在详情查看。公司业绩复用现有财报规则。订单检索最近180天内最新60条公告，最多读取3份合同/交流记录，展示至多2条带日期及源链接的原文线索；未找到不等于没有订单，定性需求也不等同已确认合同或收入。非龙头的详情可按需核验。

计算验证：`node scripts/test_hardware_metrics.cjs`。
订单接口允许跨域时访问直接更新；失败保留带原核验时间的备用披露，并明确标记缓存。可用 `node scripts/refresh_hardware_details.cjs` 维护龙头备用详情；仅显式维护任务调用，不定时执行。
