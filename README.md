# 息壤 · Dividend Radar

赛博朋克 A 股红利看板：沪深北全市场滚动现金股息率严格大于 5.0%，且总市值严格大于 500 亿元。支持搜索、市场筛选、排序、本地自选、CSV 导出及逐笔分红明细。

## 数据口径

来源：东方财富公开行情及分红送配接口。过去 365 天内已除息且标记为「实施分配」的税前每股派息之和，除以最新价。未到除息日的方案不纳入。未对窗口内送转、拆并股、配股调整，特殊股本变动公司需另行核验；一次性特别分红可能推高数值。该指标不是供应商标准 TTM 股息率，也不是预期收益。

页面展示行情源时间与抓取时间。覆盖数含源站返回的全部 A 股记录；无有效价格或无派息记录的股票不进入结果。未排除 ST，不覆盖港美股、基金和 B 股。

## 更新和部署

GitHub Actions 每日北京时间 18:30 计划抓取（可能延迟），也可手动 Run workflow。全量抓取和覆盖检查通过后原子替换快照；失败保留旧文件，部署旧快照后将任务标记失败。页面对超过 36 小时的快照或行情明确提示。

静态页面部署到 GitHub Pages，无 API 密钥。公开接口可能限流或变化，可在 Actions 日志查看失败原因。

本地更新：`python scripts/update_data.py`；预览：`python -m http.server 8000`。

## 国资标注

以东方财富公司资料中的企业性质、实控人字段分类为央企、中央金融国企、地方国企。其他公司查询最新前十大股东，对中央汇金、中国证券金融及明确国资机构作国资参股标注，并展示股东、比例和报告期。国资参股不等同国资控股，包含被动财务投资；未穷尽穿透持股关系，未识别不代表无国资。资料每日更新，失败时保留原核验日期。
